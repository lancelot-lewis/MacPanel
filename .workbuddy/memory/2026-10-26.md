## MacPanel（HomeLab Manager）— M0 + M1 实施

按 `PLAN.md` 完成 M0 文档与 M1 代码。技术路线严格遵循 ADR-001：Go + Vue 3
Web-first，**未引入 Wails / Tauri / Rust**。

### 环境事实（本机实测）

- macOS 27.0.1 (26A434) / Apple M4 / arm64 / 10 核 / 16 GiB
- 原本没有 Go，用 `mise use -g go@1.27.3` 安装（shims 在
  `~/.local/share/mise/shims`，PATH 里没有时需显式加）
- `sudo` 在沙箱内不可用（`operation not permitted`），因此**未能验证 root 下 PF 读取**
- 有 `HTTP_PROXY` 环境变量，curl 测本机端口必须加 `--noproxy '*'`

### 系统命令的真实路径（踩过坑）

- `pfctl` 在 **`/sbin/pfctl`**，不是 `/usr/sbin`
- `vm_stat` 在 `/usr/bin/vm_stat`，初版漏加到白名单导致内存一直「不可用」
- `sysctl` / `networksetup` 在 `/usr/sbin`
- `sysctl -n vm.page_inactive_count` 在 macOS 27 上**不存在**，内存统计要走 `vm_stat`

### 内存口径（重要，容易失真）

初版用 `free + speculative` 算已用，16 GiB 机器显示「已用 15.8 GiB」，明显错误。
正确口径：`已用 = 总量 − (free + speculative + purgeable + inactive) × pageSize`。
实测 11.5 GiB 已用 / 4.47 GiB 可用，与 `vm_stat` 手工核算一致。页面已标注口径。

### 验收过程中发现并修复的 3 个真实缺陷

1. **远程模式无法设置初始密码（死锁）**：`/auth/password` 注册在认证中间件之外
   （初始设置必须允许未登录），handler 内 `sessionFrom(ctx)` 永远为空 → 401；
   而登录又需要密码。修复：按「是否已设密码」分流——未设置时只允许回环地址。
2. **远程模式已登录也无法改密码**：同根，handler 拿不到会话。
   修复：加 `hasValidSession()` 手动校验 cookie，优先复用中间件注入的会话。
3. **测试报 `bind: invalid argument`**：Socket 路径超 `sun_path` 104 字节上限
   （`t.TempDir()` 把长测试名拼进路径）。修复：生产代码加 `validateSocketPath`
   提前校验并给可读错误；测试改用短路径。

教训：这些问题**跑通看不出**，只有走完整流程（尤其非 happy path）才暴露。

### 打包踩坑

- payload 里放 0750 数据目录 → `pkgbuild` 非 root 运行报 4 条
  `write: Permission denied`，且属主被写死成打包机用户。
  改为目录全部由 `postinstall` 创建，payload 只留二进制 + plist。
- `com.apple.provenance` xattr 会被转成 `._*` AppleDouble 混入载荷：
  加 `COPYFILE_DISABLE=1` + `xattr -cr`。（`pkgutil --payload-files` 仍会列出
  `._*`，但 `--expand-full` 后真实载荷是干净的，属正常现象。）
- 版本号用 `git describe --always` 会让包名变成 `HomeLabManager-<commit>.pkg`；
  改为优先取 tag，无 tag 回落 `0.1.0`。

## 下午：前端替换为 Naive UI（用户决定）

用户看完手写方案的截图后，考虑到 M2 重表单，决定"长痛不如短痛"，引入 Naive UI。
做法是**保留现有视觉**（写 themeOverrides 对齐 macOS 设置页），只借用组件能力。

### 体积（重要）

- `app.use(naive)` 全量注册：1584 kB / gzip 442 kB（原手写方案仅 143 kB / 52 kB）
- 改具名导入 + 显式注册表：243 kB / gzip（naive 187 + vue 42 + 业务 19）
- 结论：**必须按需注册**，且这个体积代价要如实告知用户（是手写方案的 4.7 倍）

### 差点漏掉的坑：页面全白但不报错

`NCard.name === "Card"` 而不是 `"NCard"`——`N` 前缀只在导出名上。
用 `c.name` 做注册名会注册成 `<Card>`，而模板写 `<NCard>`，
结果是整页空白，控制台只有一条 warn。改用显式 `[注册名, 组件]` 映射表。

### 对比度：组件库默认值普遍不达标

Naive UI 把语义色**同时**用作 Tag 的文字色和 12% 透明底，实测：
绿 3.05、橙 2.25、蓝 3.89、三级文字 3.82、深色 placeholder 3.57、
品牌块白字（深色模式）2.71。逐个压深后 10 个页面×主题组合 **0 处不达标**。

**检测方法本身也错了第一次**：脚本把半透明背景当实色算，报了 20+ 个假阳性。
正确做法是把祖先链上的背景逐层 alpha 合成到不透明底色，再算 WCAG 比值。

### 顺带修的问题

- `NLayoutSider` 是 flex 元素，`hidden lg:block` 被组件样式覆盖 → 用外层 div
- `type="primary"` 的 Tag 不受 `Tag.textColor` 控制 → 改用 `type="info"`
- `NSwitch` 的 checked/unchecked 文字白字叠滑块上 1:1 → 改为独立 label
- 审计页自绘 span 用 accent 色只有 4.0:1 → 改用 NTag（文字色已压深）

### 值得一提的收益

- 审计页换 NDataTable：白拿排序、筛选、分页、空状态
- 设置页换 NForm + rules：**提前把 M2 要用的表单校验模式跑通了**，
  实测短密码/不一致两条提示都正确
- 防火墙页新增「状态对照」表：期望/实际/是否一致并排列，比让用户自己比对两处信息好

### 验证

5 页 × 2 主题零警告、对比度 0 处不达标、移动端 390px 无溢出、
主题切换双向持久化、远程登录流程（错密码停留 / 对密码跳转）均正常。

## M5 收尾：打包链路 + 防火墙本地救援（同日晚）

用户准备进入实机测试，因此先把「只剩 finite work」的部分补齐。

### 补了什么

1. **防火墙本地救援 CLI**：`homelab-manager firewall {status,rollback,unload}`。
   刻意**不经过 IPC**——规则把 SSH 挡住时，面板那条「浏览器 → Server → IPC → Agent」
   链路本身就是断的。它直连 `firewalld.Manager` + 同一个 `PFExecutor`，
   所以 pfctl 的三层限制一条没少。
2. `firewalld.Manager.Unload`：与阶段无关地清空 anchor。
   存在的理由是 rollback 在 idle 时报 conflict，而倒计时定时器活**在 Agent 进程里**——
   Agent 若在加载后被杀，超时不会自动回滚，需要一个不依赖历史状态的兜底。
3. **打包链路**：preinstall 升级前备份、卸载脚本入库并随包安装、
   `scripts/verify-pkg.sh`（30 项静态校验，不需要 root）。

### 打包脚本里的真实缺陷（实测发现）

| 现象 | 根因 |
| --- | --- |
| `make dmg` 必然失败 | DMG 用 `git describe` 推版本、PKG 无 tag 时固化 `0.1.0`，两者不一致 |
| bash `arr[-1]` 报 bad array subscript | macOS 自带 **bash 3.2** 不支持 negative subscript |
| 升级无退路 | 缺 preinstall；补后备份 data / 令牌 / PF 现状，只留最近 5 份 |
| 安装器整个失败 | `dscl -create` 硬编码 UID/GID 350，撞号即失败 → 改为向下找空位 |
| 卸载脚本只在 build 目录、且只能交互 | 改为入库 + 装到 `/usr/local/bin/homelab-manager-uninstall`，支持 `--yes`/`--purge` |
| 日志输出 `%!(EXTRA string=reason…)` | Logger 接口是 slog 风格 key/value，却用 `fmt.Sprintf` 展开 |

### 环境事实（新人/下次会话别再踩）

- **`com.apple.provenance` 删不掉**：`xattr -c` / `-d` / `removexattr` 都返回成功但属性仍在
  （内核合成）。pkgbuild 因此为每条记录额外生成 `._xxx` AppleDouble 塞进 BOM，
  安装后系统里多几个隐藏文件。功能无害、卸载脚本会清理；换 CI/干净构建机打包应不再出现。
- **`pkgutil --expand` 要求目标目录不存在，且不会创建父目录**。
  另外 distribution 包展开一次就得到 `component.pkg` **目录**，
  对它再 expand 会报 "Could not open package for expansion"。
- **`lsbom -f`** 输出 `path<TAB>mode(八进制)<TAB>uid/gid<TAB>size`；`-pf` 只给路径。
- **`hdiutil create/convert` 在 macOS 27 已 deprecated**，将来迁 `diskutil image create`。
